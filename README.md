# Decisa AI

> An AI-powered decision and planning assistant designed to help users organize their plans, tasks, and goals.

> Asisten pengambilan keputusan dan perencanaan berbasis AI yang membantu pengguna mengatur rencana, tugas, dan tujuan mereka.

---

## 🇬🇧 English

### About

Decisa AI is a web application designed to help users make better decisions and manage their personal plans, tasks, and goals in one place.

The application combines structured planning features with AI-powered goal analysis to help users understand their goals, estimate the effort required, and break them down into actionable tasks.

### Features

- 🔐 **User Authentication**
  - User registration and login
  - Session-based authentication
  - Secure logout

- 📋 **Plan Management**
  - Create, view, edit, and delete plans
  - Set priorities and deadlines
  - Track plan status

- ✅ **Task Management**
  - Create and manage tasks
  - Set task priorities
  - Track task progress and status

- 🎯 **Goal Management**
  - Create and manage personal goals
  - Set priorities and target dates
  - Track goal information

- 🤖 **AI Goal Analysis**
  - Analyze goals using AI
  - Estimate goal difficulty and required time
  - Evaluate goal clarity
  - Identify key areas related to the goal
  - Generate suggested actionable tasks
